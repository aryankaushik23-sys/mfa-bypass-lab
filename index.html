MFA Bypass Research Lab

A controlled, ethical cybersecurity research project demonstrating three classes of MFA weakness and the technical controls that defeat each one.

NIST SP 800-63B MITRE ATT&CK IAM Security Docker Python FIDO2
Ethics & scope — This lab runs entirely on a local virtual machine. No external systems, real user accounts, or production services were targeted at any point. For defensive security education only.

Attack modules

Critical — CVSS 9.0

Module 1 — OTP interception via AiTM

Evilginx3 reverse proxy intercepts live TOTP codes and session cookies between the victim browser and Keycloak IdP.

T1111 Evilginx3 Keycloak Wireshark
Mitigation: FIDO2 / WebAuthn — origin binding defeats proxying
High — CVSS 7.5

Module 2 — MFA fatigue (push bombing)

Python script floods a test Authentik account with 20 push authentication requests, simulating approval under fatigue conditions.

T1621 Authentik Python Burp Suite
Mitigation: Number matching + rate limiting (max 5/10 min)
High — CVSS 7.1

Module 3 — SMS OTP via SIM-swap

Local Asterisk PBX and softphone clients simulate number hijacking, redirecting OTP delivery to an attacker-controlled number.

T1111 Asterisk pyotp VoIP
Mitigation: Remove SMS MFA per NIST SP 800-63B §5.2.10
